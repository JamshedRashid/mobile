# Student Task Manager

This is my Android mobile development course project.

I made a simple app called **Student Task Manager**. The app is for students who want to keep track of their study tasks.

## What the app can do

- Add a new study task
- Add a subject or course name
- Mark a task as important
- Show tasks in a list
- Open a task and see details
- Use icons/images for tasks

## What I used

- Android Studio
- Java
- XML layouts
- Git and GitHub

## Course topics used in this project

I made this project after following the Android tutorial videos.

### Part 1
I learned how to create an Android Studio project, make a simple app, use buttons and text fields, and run the app.

### Part 2
I learned about Activities and Intents. I used them to make multiple screens and move between screens.

### Part 3
I learned about ListView, custom layouts, and ImageView. I used these to show tasks in a list with icons.

## App screens

The app has three main screens:

1. **Home screen**  
   Shows the task list.

2. **Add Task screen**  
   Lets the user add a task name, subject, and importance.

3. **Details screen**  
   Shows more information about the selected task.

## How to run the app

1. Open Android Studio.
2. Clone or download this GitHub repository.
3. Open the project in Android Studio.
4. Wait for Gradle sync to finish.
5. Run the app using an emulator or Android phone.

## Project purpose

The purpose of this project was to practice the basic parts of Android development and show what I learned from the course videos.
